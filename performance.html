Corus HR – Performance

Plan, track, and evaluate employee performance.

Module: Performance | Audience: Admin / Manager / Employee | Last Updated: Dec 2025

Overview

The Performance module supports goal setting, self-reviews, manager evaluations, and final performance ratings. It provides a structured and transparent review process aligned with organizational objectives.
